# SkyLume ☼

A classic, calm weather dashboard with live conditions and a 7-day forecast.

## Features
- Live current conditions
- City search
- Browser geolocation
- 7-day forecast
- Celsius / Fahrenheit toggle
- Humidity, wind, pressure and feels-like temperature
- Responsive design
- No API key required

## Weather API
Powered by Open-Meteo. The app calls its forecast and geocoding endpoints directly from the browser.

## Deploy
This is a static site. Deploy the repository root to Vercel, Netlify, or GitHub Pages. No build command is required.
